## 🛠️ AUTOSAR ECU Migration & Hardware Redesign  
**Company:** Akkodis Germany Solutions GmbH  
**Client:** Audi AG  

### 🇬🇧 Description
- Migration of ECU software to a new microcontroller platform  
- Configuration and integration of AUTOSAR Basic Software (BSW)  
- Development of MCAL / Device Drivers  
- Implementation aligned with ASPICE (SWE.3 – Detailed Design)  
- ECU-level verification, validation & debugging  
- CAN diagnostics, DTC analysis, XCP measurement & calibration  
- Development of test software for ECU robustness testing  

### 🇩🇪 Beschreibung
- Migration von Steuergerätesoftware auf eine neue Mikrocontrollerplattform  
- Konfiguration und Integration von AUTOSAR Basissoftware (BSW)  
- Entwicklung und Anpassung von MCAL / Device Treibern  
- Umsetzung gemäß ASPICE (SWE.3 – Detaildesign)  
- Durchführung von Verifikation, Validierung und Debugging auf ECU-Ebene  
- CAN-Diagnose, DTC-Analyse sowie XCP-Messung und Kalibrierung  
- Entwicklung von Testsoftware zur ECU-Robustheitsprüfung

## 🛡️ Safety-Critical HMI Application Software  
**Company:** Silver Atena GmbH  
**Client:** Rheinmetall Landsysteme GmbH  

### 🇬🇧 Description
- Development of HMI application software on TI TMS570 with SCIOPTA RTOS  
- Implementation of real-time state machine  
- Integration of CANopen & CANsafety protocols  
- Processing of multiple hardware inputs (buttons, selectors, touch sensors)  
- Integration with generic safety software via message-based interface  
- Designed for safety-critical real-time systems  

### 🇩🇪 Beschreibung
- Entwicklung einer HMI-Applikationssoftware auf Basis TI TMS570 und SCIOPTA RTOS  
- Implementierung einer Echtzeit-Zustandsmaschine  
- Integration von CANopen- und CANsafety-Protokollen  
- Verarbeitung verschiedener Hardwareeingaben (Taster, Schalter, Sensoren)  
- Anbindung an generische Sicherheitssoftware über Nachrichten-Schnittstelle  
- Einsatz in sicherheitskritischen Echtzeitsystemen

### 🇩🇪 Beschreibung
